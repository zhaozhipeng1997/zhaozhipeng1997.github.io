研究成果

ViD：视觉语言模型性别偏见抑制
第一作者EMNLP 2026 · GitHub
  • 提出因果启发的“视觉主导”(V2L)跨模态注意力干预框架，通过后门调整抑制语言先验，无需微调即可嵌入现有 LVLM 推理流程，实现推理时性别偏见抑制。
  • 在 FACET / MS COCO / FairFace / POPE / MMMU 多基准验证：FACET 单属性性别偏见降低 14.7%，LLaVA 在 MS COCO 公平性评分由 0.6708 提升至 0.9978，同时保持推理能力与文本质量。
IntervNext：视觉语言模型机制级偏见诊断
第一作者EMNLP 2026 · GitHub
  • 提出基于因果中介分析的层级别激活替换诊断框架，将性别线索效应分解为各层激活的受控间接效应(AIE)与其余路径的直接效应，产出逐层“机制签名”，为精准干预提供依据。
  • 覆盖 LLaVA-1.5 / LLaVA-NeXT / InstructBLIP(7B/13B) 及 MiniCPM-V / InternVL3.5 等 6 模型、3 类架构；发现语言层主导输出敏感度、架构决定层间分布、反事实与表面分数分歧，并实证诊断-干预仅弱相关(r=0.33)。
SAFE：视觉语言模型幻觉诊断与抑制
第一作者EMNLP 2026 · GitHub
  • 提出免训练的对比解码框架 SAFE，通过“有视觉/去视觉”双路生成得到 token 级视觉依赖分数，用于幻觉定位与解码时惩罚，无需重训练即可部署。
  • 在 LLaVA-1.5 / InstructBLIP / Shikra 与 MMHalBench / POPE / HallusionBench / CHAIR / MMMU 五基准上验证，MMHalBench 显著超越全部基线；并揭示视觉依赖随生成衰减、幻觉时间聚集、早期干预可抑制聚集等机理。
一种电器拆解过程人员行为识别模型训练及行为识别方法及系统
2023.08–2024.12 · 第一发明人发明专利
  • 基于海尔工厂监控构建 1.02 亿图像-文本对数据集，覆盖安全装备检测、6 类拆解动作识别与危险行为预警，带领 8 人团队完成数据质检。
  • 基于 LLaVA-1.5 设计 LoRA/QLoRA(4-bit)+FlashAttention-2 微调方案（单卡 RTX 4090 达全参微调 83% 精度）；落地后拆解效率 +52%、事故 -34%。申请号 2024116855732，公布号 CN119919993A（2024.11）。
demucs_ascend910_pytorch：Demucs 音乐源分离模型昇腾 910 适配
GitHub · 9 Stars
